## Как отредактировать текст

Откройте нужный `.md` и правьте обычный текст. Например, заголовок первого экрана —
`index.md`, строка `# Юридическая помощь юридическим лицам и предпринимателям`.

Это обычный Markdown, всё как в любом редакторе:

```markdown
## Заголовок раздела
{: #services}

Абзац текста.

- Пункт списка
- Ещё пункт
```

`{: #services}` — это метка якоря. По ней работают ссылки меню и подвала
(например, кнопка «Услуги» ведёт на `#services`). Метку нужно ставить сразу под
заголовком, с новой строки.

### Как оформлены блоки

| Что нужно | Как написано в Markdown | Класс |
|---|---|---|
| Подзаголовок над разделом | текст, потом `{: .eyebrow}` | `.eyebrow` |
| Раздел с якорем | `## Заголовок` + `{: #имя}` | — |
| Сетка в две колонки (принципы, направления) | список + `{: .grid}` | `.grid` |
| Карточки с номерами (услуги) | нумерованный список + `{: .cards .cards--numbered}` | `.cards` |
| Карточки (категории дел) | список + `{: .cards}` | `.cards` |
| Шаги (порядок работы) | нумерованный список + `{: .steps}` | `.steps` |
| Врезка | цитата `> ...` + `{: .notice}` | `.notice` |
| Оговорка | текст + `{: .disclaimer}` | `.disclaimer` |
| Кнопка | `[Текст](#contacts){: .btn .btn--primary}` | `.btn` |

Если убрать последнюю строку `{: .что-то}`, блок станет обычным текстом — ничего не сломается.

## Публикация

```bash
cd "/Users/alexandrfilin/Documents/Work/1. Юрист/www/Сайт-визитка"
git add -A && git commit -m "описание правки" && git push
```

Через 1–2 минуты изменения появятся на сайте. Проверить сборку:

```bash
gh run list --limit 3
gh run watch
```

Если сборка упала, на сайте останется предыдущая рабочая версия — простоя не будет.
Ошибка: `gh run view <номер> --log-failed`.

Откат: `git revert HEAD && git push`.

## Локальный просмотр

Сборка Jekyll на этой машине не установлена, но она и не нужна: локальный сервер
отдаёт исходники `.md`, а не собранные страницы, поэтому так посмотреть сайт не выйдет.

Нужен Ruby 3.0 или новее, чтобы собрать локально:

```bash
brew install ruby
gem install jekyll
jekyll serve --baseurl ""
```

## Смена адреса

Адрес задаётся в `_config.yml`:

```yaml
url: "https://zakon-no.github.io"
baseurl: ""
```

При переходе на свой домен поменять `url` на `https://afilin.ru`, оставить
`baseurl: ""`, добавить файл `CNAME` с именем домена и поправить `robots.txt`
и `sitemap.xml`.

Почему не `afilin.github.io`: логин `afilin` на GitHub занят посторонним аккаунтом
с 2013 года, а имена пользователей и организаций занимают одно пространство — поэтому
и логин, и организация `afilin` недоступны. Сайт лежит на логине `zakon-no`, который
принадлежит вам.

## О форме обратной связи

Формы на сайте нет: заявки принимаются по телефону и по электронной почте. Кнопка
«Написать на e-mail» открывает `mailto:` с предзаполненным письмом.

Ограничение `mailto:`: письмо откроется только при настроенном почтовом клиенте,
отправка не происходит автоматически. Если понадобится приём заявок из любого
браузера, форму можно подключить через Formspree или Netlify Forms.
