# Сайт-визитка: Филин А.С. — юрист

Статический сайт частнопрактикующего юриста (г. Белгород). Чистый HTML + CSS + ванильный JS, без сборщика и внешних зависимостей: сайт публикуется на GitHub Pages как есть.

Адрес после публикации: `https://zakon-no.github.io/afilin/`

## Структура

```
index.html                                 главная страница (одностраничный лендинг)
privacy.html                               политика конфиденциальности
offer.html                                 отказ от юридической оферты
content/
  politika-konfidencialnosti.md            исходник политики
  otkaz-ot-oferty.md                       исходник отказа от оферты
assets/
  css/styles.css                           стили
  js/main.js                               мобильное меню, подсветка активного пункта, год в подвале
  img/photo.jpg                            фотография юриста (877×1100, 160 КБ)
  img/favicon.svg                          монограмма «АФ»
robots.txt
sitemap.xml
.nojekyll                                  отключает обработку Jekyll на GitHub Pages
AGENTS.md                                 правила проекта: стиль, факты, запреты
.gitignore                                исходники (Контент.docx, документ, папка img/) в репозиторий не попадают
```

## Что нужно заменить перед публикацией

В файлах `index.html`, `privacy.html` остались заглушки. Найдите их поиском по слову `___` и `example.com`:

| Что | Где искать | Заглушка |
|---|---|---|
| Номер телефона | `index.html`, `privacy.html` | `+7 (___) ___-__`, ссылки `tel:+7_______` |
| Адрес e-mail | `index.html` | `you@example.com` |
| Telegram | `index.html` | `https://t.me/______`, `@______` |
| WhatsApp | `index.html` | `https://wa.me/7__________` |
| ИНН и ОГРНИП | `index.html`, футер | `__________` в блоке `.footer__requisites` |

Быстрая проверка:

```bash
grep -n "___" index.html privacy.html
```

Если домен будет собственным, замените `zakon-no.github.io/afilin` на него в `index.html` (тег `canonical`, `og:url`), `privacy.html`, `offer.html`, `robots.txt`, `sitemap.xml`. Для домена добавьте в корень репозитория файл `CNAME` с именем домена.

## Работа с правками

Папка уже является git-репозиторием (ветка `main`, remote `zakon-no/afilin`). Перед каждой правкой вносите изменения отдельным коммитом — так любую правку можно посмотреть и откатить:

```bash
git status              # что изменено
git diff                # подробности правок
git diff assets/css/styles.css   # только стили
git add -A && git commit -m "описание правки"
git log --oneline       # история
```

Правила проекта для ИИ-агентов зафиксированы в `AGENTS.md` — прочитайте этот файл перед любыми изменениями.

## Локальный просмотр

```bash
cd "Сайт-визитка"
python3 -m http.server 8000
```

Откройте http://localhost:8000 — так сайт работает корректно (как на GitHub Pages).

## Публикация на GitHub Pages

Репозиторий `zakon-no/afilin` уже создан локально и подключён как `origin`. Осталось:

```bash
git push -u origin main
```

Затем в GitHub: Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`. Через несколько минут сайт будет доступен на `https://zakon-no.github.io/afilin/`.

Полная последовательность с нуля:

```bash
cd "Сайт-визитка"
git init
git add .
git commit -m "Сайт-визитка юриста"
git branch -M main
git remote add origin https://github.com/zakon-no/afilin.git
git push -u origin main
```

Исходники `Контент.docx`, `Договор оказания юридических услуг_шаблон.doc` и папку `img/` (оригинал фотографии) в репозиторий публиковать не нужно — на сайте они не используются. Их можно исключить в `.gitignore` или удалить из локальной копии перед первым коммитом.

## О форме обратной связи

Форма на сайте не используется: заявки принимаются по телефону, в мессенджерах и по электронной почте. Кнопки «Написать» открывают `mailto:` с предзаполненным письмом.

Ограничение `mailto:`: письмо откроется только при настроенном почтовом клиенте, отправка не происходит автоматически. Если понадобится надёжный приём заявок в любом браузере, форма подключается одной правкой — например, через Formspree или Netlify Forms (понадобится регистрация и ключ).

## Правовая оговорка

Тексты раздела «Политика конфиденциальности» и «Отказ от юридической оферты» подготовлены как типовые и требуют проверки перед публикацией. Их исходники лежат в папке `content/`, актуальные HTML-страницы — в корне репозитория.
