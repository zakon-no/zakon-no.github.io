# Сайт юриста Филина А.С. — Белгород

Одностраничный сайт. Весь текст — в **одном файле `index.md`**.

## Как работать

1. Откройте папку проекта в VS Code: **File → Open Folder**
2. Сервер поднимется сам, браузер откроется сам
3. Правьте **`index.md`**, сохраняйте — страница обновится сама

Адрес: **http://localhost:8080/**

Никаких команд в Терминале. Никаких портов, которые надо помнить. `Cmd + R`
не нужен — страница перезагрузится сама.

## Порядок действий

| Хочу | Что делаю |
|---|---|
| Поменять текст | Правлю `index.md`, сохраняю — всё |
| Посмотреть сайт | http://localhost:8080/ |
| Остановить сервер | Кнопка **■** у задачи «Сайт: локальный сервер» в панели VS Code |
| Опубликовать | Source Control → написать что изменил → **✓** → **Sync Changes** |

## Если что-то пошло не так

| Симптом | Что сделать |
|---|---|
| В браузере «Не удаётся подключиться» | **Terminal → Run Task →** `Сайт: локальный сервер` |
| Вместо сайта старая версия | Обновите страницу: **Cmd + R** |
| Порт занят, сервер не поднялся | Остановите задачу «Сайт: локальный сервер» в другом окне VS Code |
| Случайно испортили `index.md` | **Source Control →** выбрать файл → **↩ Отменить изменения** |

Сервер запускается сам при каждом открытии папки. Если VS Code спросит
«Разрешить автоматические задачи?» — ответьте **Да**.

## Как устроен `index.md`

```markdown
## Заголовок раздела

*мелкая надпись над заголовком*

Первый абзац — выделяется крупнее.

Остальной текст, списки и подзаголовки.
```

Разделов девять, порядок менять не нужно — от него зависит оформление:

| № | Раздел | Фон |
|---|---|---|
| 1 | Юридическая помощь… | серый |
| 2 | Филин Александр Сергеевич | белый, фото слева |
| 3 | На чём строится работа | белый, иконки |
| 4 | С кем работаю | серый, карточки |
| 5 | Что входит в работу | белый, плитки |
| 6 | Как я работаю | серый, крупные цифры |
| 7 | С чем обращаются | белый, карточки |
| 8 | Частые вопросы | серый, аккордеон |
| 9 | Связаться со мной | тёмный |

Если разделов вдруг не девять, при сборке появится предупреждение.

### Что понимает разметка

| Что нужно | Как написать |
|---|---|
| Подзаголовок внутри раздела | `### Текст` |
| Список | `- Пункт` |
| Нумерованный список | `1. Пункт` |
| Выделение | `**жирный**`, `*курсив*` |
| Ссылка | `[текст](https://адрес)` |
| Врезка-предупреждение | строки, начинающиеся с `>` |
| Карточка с подзаголовком | `- ### Подзаголовок` + текст с отступом |

Первый список в разделе превращается в карточки или плитки автоматически,
остальные остаются обычными списками.

## Что где лежит

```
index.md      ← весь текст сайта, редактируете только его
build.py      ← сборщик: index.md → index.html
serve.py      ← локальный сервер со слежением за index.md
index.html    ← готовый сайт, создаётся автоматически
offer.md      ← текст отказа от оферты
offer.html    ← готовая страница оферты, создаётся автоматически
assets/
  css/styles.css   стили
  js/main.js       меню и аккордеон
  img/photo.jpg    фотография
  img/favicon.svg  монограмма «АФ»
.vscode/       задачи для кнопок в VS Code
README.md      этот файл
AGENTS.md      правила проекта
```

**`index.html` и `offer.html` править нельзя** — они перезаписываются при
каждом сохранении `index.md`. В начале каждого такого файла есть пометка об
этом.

## Как отправить изменения на сайт

1. Слева нажмите **Source Control** (значок ветки)
2. Если сверху написано, что есть изменения на GitHub, — нажмите **Pull**
3. В поле **Commit** напишите, что изменили, и нажмите **✓**
4. Нажмите **Sync Changes**

Через 1–2 минуты изменения появятся на **https://zakon-no.github.io/**

## Контакты

Телефон и почта меняются в двух местах:

- в самом верху `index.md`, между строками `---` — для шапки и подвала;
- в разделе «Связаться со мной» — обычным пунктом списка.

Кнопка «Написать» собирает письмо сама, текст письма задан в `build.py`.
