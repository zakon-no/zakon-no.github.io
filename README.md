## Структура

`_layouts/` содержит только структуру HTML. Весь видимый текст — в `_includes/*.md`.

## Как отредактировать текст

Откройте нужный файл в `_includes/` и правьте обычный текст. Например, чтобы поменять заголовок первого экрана — `_includes/hero.md`.

Разметка внутри `.md` — это обычный HTML, а не синтаксис Markdown: теги `<p>`, `<ul>`, `<h3>` пишутся напрямую, как в обычном файле. Так ничего не ломается при вёрстке.

## Локальный просмотр

Сборка Jekyll на этой машине не установлена, но она и не нужна для просмотра результата: локальный сервер отдаёт исходники, а не собранные страницы, поэтому так не выйдет.

Вместо этого после пуша проверяйте сайт по боевому адресу — он обновляется за 1–2 минуты. Локально доступен только просмотр собранной версии:

```bash
gh run list --workflow pages --limit 3
gh run watch
```

Если хотите собирать локально (нужен Ruby 3.0+):

```bash
brew install ruby
gem install jekyll
jekyll serve
```

## Публикация

Репозиторий `zakon-no/afilin` уже подключён как `origin`, GitHub Pages включён.

```bash
cd "/Users/alexandrfilin/Documents/Work/1. Юрист/www/Сайт-визитка"
git add -A && git commit -m "описание правки" && git push
```

Через 1–2 минуты изменения появятся на сайте. Откат последней правки: `git revert HEAD` и снова `git push`.

Если сборка на GitHub упала, на сайте останется предыдущая рабочая версия — простоя не будет. Посмотреть ошибку: `gh run list --workflow pages` и `gh run view <номер> --log-failed`.

## Смена адреса

Адрес задаётся в `_config.yml`:

```yaml
url: "https://zakon-no.github.io"
baseurl: "/afilin"
```

- Свой домен: `url: "https://afilin.ru"`, `baseurl: ""`, плюс файл `CNAME` в корне с именем домена.
- Организация с одноимённым репозиторием (`afilin-law`): изменить только `baseurl: "/afilin-law"`.

Имя `afilin` на GitHub занято посторонним аккаунтом (создан в 2013 году), поэтому адрес `afilin.github.io` недоступен: имена пользователей и организаций используют одно пространство. Свободны `afilin-law`, `afilinlegal`, `afilinlaw` — при создании организации с таким именем и репозитория с тем же именем получится адрес вида `https://afilin-law.github.io`.

## О форме обратной связи

Формы на сайте нет: заявки принимаются по телефону и по электронной почте. Кнопка «Написать на e-mail» открывает `mailto:` с предзаполненным письмом.

Ограничение `mailto:`: письмо откроется только при настроенном почтовом клиенте, отправка не происходит автоматически. Если понадобится надёжный приём заявок из любого браузера, форму можно подключить через Formspree или Netlify Forms.
