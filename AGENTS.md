## 1. Стек и структура

Jekyll. GitHub Pages собирает сайт сам при каждом пуше — локально ничего
устанавливать не нужно. Никаких npm-зависимостей, плагинов и внешних CDN.
Файл `.nojekyll` удалён: без него Jekyll не запустится.

```
index.md            главная страница: только шапка, ТЕКСТ ЗДЕСЬ НЕ ХРАНИТСЯ
_sections/01-about.md      блок «О юристе»
_sections/02-hero.md       главный блок с заголовком и кнопками
_sections/03-principles.md блок «Принципы работы»
_sections/04-directions.md блок «Направления»
_sections/05-services.md   блок «Услуги»
_sections/06-process.md    блок «Порядок работы»
_sections/07-practice.md   блок «Категории дел»
_sections/08-faq.md        блок «Частые вопросы»
_sections/09-contacts.md   блок «Контакты»
_includes/section.html     обёртка блока: <section>, заголовок, вступление
_layouts/default.html      каркас: <head>, шапка, подвал, цикл по блокам
offer.md                   отказ от юридической оферты (страница есть, ссылка отключена)
_config.yml                настройки: url, baseurl, коллекция sections, исключения
Gemfile, Gemfile.lock      локальный запуск Jekyll
assets/css/styles.css      все стили
assets/js/main.js          мобильное меню, активный пункт меню, год в подвале
assets/img/photo.jpg       фотография (877×1100)
assets/img/favicon.svg     монограмма «АФ»
```

**Главная страница собрана из независимых блоков.** Каждый блок — свой файл в
`_sections/` и свой тег `<section class="section">`. Файл `index.md` содержит
только заголовок и описание страницы, текста в нём нет.

**Главное правило: текст правится в `_sections/*.md`, `offer.md`,
никогда не в собранном HTML.** Это обычный Markdown: `##` — заголовок,
`-` — список, `**жирный**` — выделение.

Шапка блока задаётся во вводных данных файла (между `---`), а не в тексте:

```
---
order: 5                # порядок блоков на странице, по возрастанию
anchor: services        # якорь для меню; можно убрать
eyebrow: Услуги         # надпись мелким шрифтом над заголовком
title: Что входит в работу   # сам заголовок
heading: h1             # h1 только у блока 02-hero, по умолчанию h2
modifier: section--alt  # фон блока: section--alt серый, section--deep тёмный
photo: /assets/img/photo.jpg      # фото, необязательно
lead: Текст-вступление            # абзац под заголовком
---
```

Оформление текста задаётся метками kramdown на отдельной строке сразу под блоком:

```
## Заголовок раздела
{: #services}

- Пункт
{: .grid}
```

Классы списков: `.grid`, `.cards`, `.cards--numbered`, `.steps`, `.facts`,
`.faq`, `.hero__facts`, `.contacts`, `.notice`, `.disclaimer`, `.btn`.
Если убрать метку — блок станет обычным текстом, ничего не сломается.

Фон блоков чередуется, чтобы страница не была однородной:

| Файл | Фон | Якорь |
|---|---|---|
| `01-about.md` | белый | `#about` |
| `02-hero.md` | серый `--alt` | — |
| `03-principles.md` | белый | `#principles` |
| `04-directions.md` | серый | `#directions` |
| `05-services.md` | белый | `#services` |
| `06-process.md` | серый | `#process` |
| `07-practice.md` | белый | `#practice` |
| `08-faq.md` | серый | `#faq` |
| `09-contacts.md` | тёмный `--deep` | `#contacts` |

Классы `{: #якорь}` внутри блоков не нужны — якорь задаётся полем `anchor`.
Не переименовывай якоря `#about`, `#principles`, `#directions`, `#services`,
`#process`, `#practice`, `#faq`, `#contacts` без согласования.

`auto_ids: false` в `_config.yml` — чтобы kramdown не плодил кириллические
`id` вида `#юридическим-лицам`.

Стили — только в `assets/css/styles.css`. Не создавай новых CSS-файлов.

Шрифты только системные: `Georgia, "Times New Roman", serif` для заголовков,
`-apple-system, "Segoe UI", Arial, sans-serif` для текста. Google Fonts и любые
внешние запросы запрещены.

Правку проверяй так — локально Jekyll работает:

```bash
export PATH="/opt/homebrew/bin:/opt/homebrew/sbin:$PATH"
export PATH="$(ruby -r rubygems -e 'print Gem.bindir'):$PATH"
bundle exec jekyll build        # проверка сборки
bundle exec jekyll serve        # http://localhost:4000
```

После `git push` смотри лог сборки — `gh run list --workflow pages`,
`gh run view <номер> --log-failed`.

## 2. Стиль — главное требование

Сайт должен вызывать доверие и транслировать статус, опыт и надёжность.

**Запрещено:**
- оценочные маркетинговые приёмы: «лучший», «№1», «первый», «уникальный»,
  «гарантируем результат», «100%», «быстро и качественно», «эксперт №»;
- юридически недопустимые обещания результата по конкретным делам;
- эмодзи, восклицательные знаки в заголовках, «кричащие» формулировки;
- анимация: допустимы только `transition` на hover и плавный скролл.
  Никаких параллаксов, счётчиков, карусель, анимации появления;
- тени-«жировки», скругления больше 4 px, градиенты, декоративные иллюстрации.

**Обязательно:**
- сдержанная типографика: заголовки `var(--font-head)`, вес 400, без жирного;
- тонкие линии 1 px (`var(--line)`), цветовые акценты только `var(--accent)`;
- ссылка «через подчёркивание» не делается, но интерактивные элементы — да.

**Палитра (не менять без согласования):**

| Токен | Значение | Назначение |
|---|---|---|
| `--bg` | `#ffffff` | фон |
| `--bg-alt` | `#f6f7f9` | секции через одну, карточки |
| `--bg-deep` | `#14263b` | подвал |
| `--text` | `#1b1f24` | основной текст |
| `--text-muted` | `#5a626b` | вторичный текст |
| `--accent` | `#1c3a5e` | акцент, ссылки, номера |
| `--line` | `#e3e6ea` | разделители |

## 6. Структура главной страницы

Порядок блоков задан владельцем, менять его без согласования нельзя:

`header` → `#about` (О юристе) → `hero` (заголовок и кнопки) →
`#principles` (Принципы работы) → `#directions` (Направления) →
`#services` (Услуги) → `#process` (Порядок работы) →
`#practice` (Категории дел) → `#faq` (Вопросы) → `#contacts` (Контакты) → `footer`

Каждый блок — отдельный файл `_sections/NN-name.md` и отдельный `<section>`.
Порядок задаётся полем `order`, фон — полем `modifier`, якорь — полем `anchor`.

- `01-about.md` — идёт ПЕРВЫМ, по решению владельца: посетитель сразу видит юриста,
  фото слева, квалификация и специализация;
- `02-hero.md` — единственный `h1` на странице, преимущества и кнопки
  «Получить консультацию» и «Услуги»;
- `03-principles.md` — отдельный блок, в `#about` принципов быть не должно;
- `09-contacts.md` — тёмный фон `--deep`, реквизиты, кнопки, оговорка об оферте;
- ровно один `h1` на страницу, далее `h2` → `h3`, без пропусков уровней.
  `h1` находится в блоке hero, то есть ниже `h2` из `#about` — это осознанное
  решение владельца, не считать ошибкой.

## 8. Адрес сайта

Адрес задаётся в `_config.yml`: `url` и `baseurl`. Теги `canonical` и `og:url`
собираются из них автоматически, дублировать руками не нужно. Отдельно правится
`robots.txt` и `sitemap.xml`.

Текущее состояние: `url: https://zakon-no.github.io`, `baseurl: ""`.
Репозиторий: `zakon-no/zakon-no.github.io`.

**Адрес `afilin.github.io` недостижим.** Логин `afilin` на GitHub занят
посторонним аккаунтом, созданным в 2013 году. Имена пользователей и организаций
занимают одно пространство, поэтому организацию с именем `afilin` создать нельзя.
Логин `filin` тоже занят посторонним аккаунтом.

Сайт перенесён на логин `zakon-no` — это собственность владельца:
`https://zakon-no.github.io/`.

Достижимые варианты дальше:
- собственный домен — рекомендуется, выглядит существенно статуснее;
- своя организация + одноимённый репозиторий: `afilin-law`, `afilinlegal`,
  `afilinlaw` — свободны, дадут адрес вида `https://afilin-law.github.io`.

При любом переходе: изменить `url`/`baseurl` в `_config.yml`, поправить
`robots.txt` и `sitemap.xml`, для домена добавить файл `CNAME`.
